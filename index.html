🐾 Monopoloy Go Album Extractor

Simplifiez vos échanges de stickers Monopoly Go

Générez instantanément vos listes de cartes manquantes et doubles au format texte.

🚀 Installer le Script

Comment ça marche ?

    Pour Firefox :

  1. Assurez-vous d'avoir l'extension Violentmonkey (préférable) ou Greasemonkey installée.

    2. Pour Chrome :

  2. Assurez-vous d'avoir l'extension TamperMonkey installée. Une fois l'extension installée, il faudra aller dans la gestion de l'extension et activer l'option "Autoriser les scripts utilisateurs

  3. Cliquez sur le bouton bleu ci-dessus pour installer/mettre à jour.
  4. Allez sur votre page de jeu Monopoly Go web et connectez-vous.
  5. Dès que vous ouvrez l'album, un bouton bleu "Bilan Album" apparaîtra en bas à droite !
  6. Le script intercepte juste les données affichées et les reformate, il ne se connecte pas à votre compte
