🐾 Monopoloy Go Album Extractor

Simplifiez vos échanges de stickers Monopoly Go

Générez instantanément vos listes de cartes manquantes et doubles au format texte.

Le script se contente juste d'intercepter les données déjà affichées et les reformate proprement, il ne se connecte jamais directement à votre compte !

🚀 Installer le Script

Comment ça marche ?

    Pour Firefox :

  1. Assurez-vous d'avoir l'extension Violentmonkey (préférable) ou Greasemonkey installée.

    2. Pour Chrome :

  2. Assurez-vous d'avoir l'extension TamperMonkey installée. Une fois l'extension installée, il faudra aller dans la gestion de l'extension (Image 1) et activer l'option "Autoriser les scripts utilisateurs (Image 2)

    3. Ensuite :

  3. Cliquez sur le bouton bleu ci-dessus pour installer/mettre à jour.
  4. Allez sur votre page web du jeu Monopoly Go et connectez-vous.
  5. Rendez-vous alors sur la page album, une fois la page chargée, vous verrez un bouton bleu "Bilan Album" apparaîtra en bas à droite !
