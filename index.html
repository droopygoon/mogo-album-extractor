📖 Guide d'utilisation complet

Découvrez comment exploiter toutes les fonctionnalités de l'application pour gérer votre album et organiser vos échanges efficacement.

1 Onglet : Mon Inventaire

Cet onglet centralise vos données personnelles d'album et gère la sécurisation de votre compte.

  • • ID Joueur : Votre identifiant unique généré automatiquement (ex: EXEMPLE-A1B2). Utile pour que vos amis vous identifient sur le réseau.
  • • Copier : Copie instantanément votre ID dans le presse-papier pour le transmettre facilement à un ami.
  • • Importer ID : Permet d'importer un ID existant si vous changez d'appareil ou d'ordinateur.
  • • 🔓 Sécuriser ID / 🔒 Sécurisé : Ouvre un panneau pour créer un mot de passe et sélectionner une question de sécurité (avec réponse). Une fois configuré, le mot de passe est retenu automatiquement sur votre navigateur pour ne plus avoir à le saisir.
  • • ☁️ Partager mon Album : Publie votre inventaire (manquantes/doubles) sur le serveur. Indispensable pour que vos amis puissent voir ce que vous avez en double lors d'une recherche.
  • • Case "Afficher les Ors [Golds]" : Cocher cette case inclut les cartes Dorées (affichées entre crochets [103] et dorées) dans vos listes. Décocher masque ces cartes (car non échangeables hors événements spéciaux).
  • • ❌ MANQUANTES & ✅ DOUBLES : Vos listes complètes classées par numéro de set. Le bouton "Copier" au-dessus de chaque bloc permet de copier le texte formaté pour le coller sur Facebook ou Discord.

2 Onglet : 🤝 Comparer 1 à 1

Comparez précisément votre album avec celui d'un ami spécifique pour préparer un échange direct.

  • • Sélecteur "Favoris / Amis" : Choisissez un ami déjà enregistré pour charger automatiquement son identifiant et ses données.
  • • Champs ID & Surnom : Saisissez l'ID d'un joueur et attribuez-lui un surnom personnalisé (ex: MARIE_FB) pour le reconnaître rapidement dans vos listes.
  • • Boutons d'action :
      - Récupérer : Charge les dernières données partagées par cet ami sur le cloud.
      - ⭐ (Sauvegarder) : Enregistre/Modifie le joueur et son surnom dans votre liste de favoris.
      - 🗑️ (Supprimer) : Retire le joueur de vos favoris.
  • • Date de mise à jour : Indique l'horodatage exact du dernier partage effectué par l'ami (ex: Mis à jour : 31/08 à 14:30).
  • • Zones de texte "SES MANQUANTES" / "SES DOUBLES" : Affiche les listes de l'ami. Vous pouvez également y coller directement le texte brut de n'importe quel joueur et cliquer sur "Comparer manuellement".
  • • Résultats d'échange :
      - 🎁 Recevables : Liste des cartes qu'il vous manque et que cet ami possède en double.
      - 🤝 Donnables : Liste des cartes que cet ami cherche et que vous possédez en double.

3 Onglet : 🔎 Recherche Globale

Scannez l'ensemble de vos amis enregistrés en une seule action pour savoir immédiatement qui possède les cartes qui vous manquent.

  • • Filtre "Actifs depuis" : Permet de filtrer la recherche selon la récence de mise à jour de vos amis (Aujourd'hui, 3 jours, 7 jours...) afin d'éviter de contacter des joueurs inactifs.
  • • Bouton "Lancer la Recherche" : Interroge le serveur pour l'intégralité de vos favoris et croise automatiquement leurs doubles avec vos cartes manquantes.
  • • Résultats synthétiques par Set : Organise les cartes qu'il vous manque set par set et vous indique clairement le nom de chaque ami qui en possède un double (ex: Sticker 12 disponible chez : MARIE_FB, JEAN_M).
