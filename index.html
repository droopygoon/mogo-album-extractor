🚀 Installer le Script (v1.90)

Le script intercepte uniquement les données de votre navigateur. Aucune connexion directe à votre compte n'est effectuée.

⚙️ Guide d'installation

🦊 Firefox (PC & Android)

1 Installez l'extension Violentmonkey (recommandé).

Les extension Tampermonkey et Greasemonkey devraient également fonctionner mais pas testé.

2 Cliquez sur le bouton d'installation bleu ci-dessus.

3 Acceptez l'installation du script utilisateur

🌐 Chrome / Edge (PC)

1 Installez TamperMonkey.

2 Important : Rendez-vous dans la section de gestion de l'extension (voir image 1) pour activer l'autorisation des scripts utilisateurs (image 2).

3 Cliquez sur le bouton d'installation bleu ci-dessus.

Ensuite :

4 Rendez-vous sur la page web de Monopoly Go.

5 Si ce n'est pas déjà fait, connecctez-vous à votre compte et allez sur la page album.

6 Une fois la page chargée, vous verrez un bouton bleu "Bilan Album" apparaîtra en bas à droite !
