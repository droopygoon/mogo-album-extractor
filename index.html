2 Cliquez sur le bouton d'installation bleu ci-dessus.

3 Acceptez l'installation du script utilisateur.

🌐 Chrome / Edge (PC)

1 Installez TamperMonkey.

2 Important : Rendez-vous dans la section de gestion de l'extension pour activer l'autorisation des scripts utilisateurs.

6 Une fois la page chargée, le bouton bleu "🐾 Bilan Album" apparaîtra en bas à droite !

📖 Guide d'utilisation complet

Découvrez comment exploiter toutes les fonctionnalités de l'application pour gérer votre album et organiser vos échanges efficacement.

1 Onglet : Mon Inventaire

Cet onglet centralise vos données personnelles d'album et gère la sécurisation de votre compte.

  • • ID Joueur : Votre identifiant unique généré automatiquement (ex: EXEMPLE-A1B2). Utile pour que vos amis vous identifient sur le réseau.
  • • Copier : Copie votre ID dans le presse-papier pour le transmettre à vos amis.
  • • Importer ID : Permet d'importer un ID existant si vous changez d'appareil.
  • • 🔓 Sécuriser ID / 🔒 Sécurisé : Ouvre un panneau pour définir un mot de passe et une question secrète. Le mot de passe et la réponse de sécurité sont hachés en SHA-256 pour une sécurité optimale. Des interfaces distinctes vous permettent de mettre à jour le mot de passe ou de le réinitialiser en cas d'oubli grâce à votre question secrète.
  • • ☁️ Partager mon Album : Publie votre inventaire sur le Cloud ainsi que la saison d'album actuelle. Indispensable pour que vos amis vous trouvent lors d'une recherche.
  • • Case "Afficher les Ors [Golds]" : Permet d'inclure ou de masquer les cartes Dorées dans toutes les vues et comparaisons.
  • • ❌ MANQUANTES & ✅ DOUBLES : Vos listes complètes prêtes à copier pour Facebook ou Discord.

2 Onglet : 🤝 Comparer 1 à 1

Comparez précisément votre album avec celui d'un ami spécifique pour préparer un échange direct.

  • • Sélecteur "Favoris / Amis" : Choisissez un ami enregistré pour charger automatiquement son ID et son alias.
  • • Champs ID & Surnom : Saisissez l'ID d'un joueur et attribuez-lui un surnom personnalisé.
  • • Boutons d'action :
      - Récupérer : Charge les données Cloud de l'ami et affiche un avertissement si l'ami est resté sur une ancienne saison d'album.
      - ⭐ (Sauvegarder) : Enregistre/Modifie le favori.
      - 🗑️ (Supprimer) : Retire le favori.
      - 🧹 RàZ : Réinitialise rapidement la zone d'affichage et de comparaison.
  • • Date & Saison d'album : Indique la date de mise à jour et signale par un avertissement si l'ami est sur un album différent du vôtre.
  • • Résultats d'échange :
      - 🎁 Recevables : Cartes qu'il vous manque et que cet ami a en double.
      - 🤝 Donnables : Cartes qu'il cherche et que vous avez en double.

3 Onglet : 🔎 Recherche Globale

Scannez l'ensemble de vos amis enregistrés pour savoir immédiatement qui possède vos cartes manquantes.

  • • Filtre "Actifs depuis" : Filtre les amis selon leur récence (Aujourd'hui, 3 jours, 7 jours...).
  • • Contrôle de Saison : Écarte automatiquement les amis dont l'album enregistré ne correspond plus à l'album de la saison en cours.
  • • Bouton "Lancer la Recherche" : Effectue l'analyse croisée et mémorise vos réglages.
  • • Résultats synthétiques : Présente la liste des cartes manquantes set par set avec les amis disposant d'un double disponible.
