# 🐾 Monopoly Go - Album Extractor & Comparator

![Version](https://img.shields.io/badge/version-1.64-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Un script simple et puissant pour extraire vos listes de stickers **Monopoly Go** et les comparer instantanément avec vos amis pour optimiser vos échanges.

---

## 🚀 Installation Rapide

Pour installer le script, rendez-vous sur la page officielle du projet :
👉 **[Accéder à la page d'installation](https://droopygoon.github.io/mogo-album-extractor/)**

*(Nécessite Violentmonkey, Tampermonkey ou Greasemonkey selon votre navigateur)*

---

## ✨ Fonctionnalités

### 📋 Extracteur d'Album
* **Génération automatique** : Plus besoin de noter vos cartes à la main.
* **Format Pro** : Un format texte propre (`Set-ID,ID,ID`) facile à copier-coller sur Facebook, Discord ou Messenger.
* **Filtre Golds** : Possibilité d'afficher ou de masquer les cartes Or selon vos besoins.

### 🤝 Comparateur Intelligent (Nouveauté v1.64)
* **Match Automatique** : Collez les listes d'un ami et voyez directement ce que vous pouvez vous échanger.
* **Gain de temps** : Le script compare "Vos Manquantes vs Ses Doubles" et "Vos Doubles vs Ses Manquantes".
* **Sécurité Échanges** : Filtre automatiquement les cartes Or (non échangeables) pour éviter les erreurs.

---

## 🛠️ Comment l'utiliser ?

1. Connectez-vous à [Monopoly Go Web](https://www.monopolygo.com/).
2. Ouvrez votre **Album** en jeu.
3. Cliquez sur le bouton bleu **"Bilan Album"** qui apparaît en bas à droite.
4. **Pour extraire :** Utilisez les boutons "Copier" dans l'onglet "Mon Inventaire".
5. **Pour comparer :** Allez dans l'onglet "Comparer", collez les listes de votre ami et cliquez sur le bouton de comparaison.
